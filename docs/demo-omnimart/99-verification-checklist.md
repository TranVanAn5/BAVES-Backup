# Checklist xác minh demo OmniMart (learner)

Dùng sau khi chạy hết 4 sprint theo thư mục này.

## Setup
- [ ] Login `learner@gmail.com` / account demo đã cấp
- [ ] Scenario **OMNI-001** / Intermediate free mở được
- [ ] TemplateCodes hiện **DEL-02, DEL-03, DEL-04, DEL-05, DEL-07, DEL-08** (không tên mock generic)

## Sprint 1
- [ ] Interview theo thứ tự file `sprint-01/01-interview-script.md` (không paste cả list)
- [ ] DEL-02 BAP: submit **v1** (còn lỗ) → chỉnh **v2** đầy đủ
- [ ] DEL-03 Stakeholder: tương tự v1 → v2
- [ ] Review Sprint: có grade / feedback AI; không bị ép review UI lệch flow

## Sprint 2
- [ ] Ops → CS → IT đúng thứ tự (`01` → `02` → `03`)
- [ ] DEL-04 Elicitation v1 rồi v2 (có Fact / Assumption / Conflict)
- [ ] DEL-05 BRD v1 rồi v2 (BR testable + metrics + NFR)
- [ ] Review Sprint + snapshot so với Sprint 1 nếu UI hỗ trợ

## Sprint 3 (E1)
- [ ] Đọc event E1 trước khi hỏi
- [ ] Follow-up Ops → CS → IT Turn-by-Turn
- [ ] DEL-07 CR v1 rồi v2 (delta testable, temporary vs permanent, acceptance)
- [ ] Review Sprint

## Sprint 4 (E2)
- [ ] Đọc event E2 Flash Sale
- [ ] Ops → CS → IT flash scripts
- [ ] DEL-08 SRS v1 rồi v2 (traceability, eval order, NFR số, error catalog)
- [ ] Review Sprint cuối

## Artifacts / hồ sơ
- [ ] Artifacts không còn mock deliverable giả
- [ ] ArtifactSnapshotJson / lịch sử review phản ánh bản đã submit (không chỉ overwrite mù)

## Pass criteria demo giảng viên
- Learner chứng minh được: hỏi đúng mục đích từng sprint, có tiến hóa v1→v2, và deliverable map DEL codes.
