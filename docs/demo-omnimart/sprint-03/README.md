# Sprint 3 — Event E1: Manual sync delay / lệch tồn nóng

## Mục đích sprint
Khi event **E1** kích hoạt (độ trễ sync / lệch tồn cấp độ vận hành), BA phải:
1. Xác nhận triệu chứng với Ops / CS / IT theo **thứ tự**.
2. Phân biệt triệu chứng vs nguyên nhân vs workaround tạm.
3. Cập nhật / bổ sung yêu cầu (thường **DEL-07** Change Request hoặc BRD delta) — **v1 còn lỗ hổng → v2 đầy đủ**.

## Thứ tự làm
1. Đọc event trên UI (không bỏ qua mô tả E1).
2. Phỏng vấn theo `01-followup-ops.md` → `02-followup-cskh.md` → `03-followup-it.md` (Turn-by-Turn).
3. Viết DEL-07 v1 rồi v2 theo `04-del-07-change-v1-v2.md`.
4. Review Sprint.
